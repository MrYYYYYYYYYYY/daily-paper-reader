## 摘要
具备价值意识的AI系统需要人类价值的显式计算表示（基础）及其聚合成价值系统，以便将其决策与我们的决策对齐。由于此类表示难以获取，价值学习试图通过观察人类行为来推断它们。本文解决了生成式AI中缺乏基于基础的价值学习方法的问题：现有方法通常复制人类偏好，而未意识到价值对齐的多维结构，或者缺乏原则性的价值系统引导方法。为弥补这些不足，我们将一种先前验证过的价值系统学习方法适配到生成式AI设置中，该方法基于成对的提示-响应偏好数据，同时学习：i) 通过多目标奖励模型实现一组价值的基础，以及ii) 以先前基础模型的加权线性标量化形式表示的价值系统。为确保所学的价值系统基于连贯的价值表示，我们的算法动态优先考虑基础学习过程。我们在提示-响应偏好数据集上对基线方法和一种当代方法进行了评估。结果显示，与基线相比，性能具有竞争力且权衡最小，同时提高了可解释性。

## Abstract
Value-aware AI systems require explicit computational representations of human values (groundings) and their aggregation into value systems in order to align their decisions with ours. As such representations are difficult to elicit, value learning seeks to infer them by observing human behaviour. This work addresses the lack of grounded value learning methods in generative AI: existing approaches typically replicate human preferences without awareness of the multidimensional structure of value alignment, or lack principled value system elicitation methods. To address these gaps, we adapt a previously validated value system learning method to the generative AI setting, which, based on pairwise prompt-response preference data, simultaneously learns: i) an implementation of a grounding for a set of values given by a multi-objective reward model, and ii) a value system representation in the form of a weighted linear scalarization of the previous grounding model. To ensure that the learned value systems are based on coherent value representations, our algorithm dynamically prioritizes the grounding learning process. We evaluate the method against baselines and a contemporary method on prompt-response preference datasets. Results show competitive performance and minimal trade-offs against the baselines, while improving explainability.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在生成式AI（如大语言模型LLMs）中，现有价值对齐方法通常没有意识到价值对齐的多维结构——它们只是复制人类偏好，而不分解不同人类价值（如helpfulness、safety等）的贡献。缺乏基于原则的价值系统（value system）引出方法，导致无法真正理解用户的价值偏好。
- **整体含义**：为了使AI系统具备价值意识（value-aware），需要显式地表示人类价值的“基础”（grounding）以及价值系统（即用户对不同价值的相对重视程度）。本文旨在填补这一空白，提出一种在生成式AI中同时学习价值基础和价值系统的方法，从而在保持竞争性能的同时提升可解释性。

### 2. 论文提出的方法论

- **核心思想**：基于成对的prompt-response偏好数据，同时学习：
    1. **价值基础（grounding）**：通过一个多目标奖励模型（multi‑objective reward model）实现，即每个价值对应一个奖励函数 \(R_{v_i}(\tau)\)。
    2. **价值系统（value system）**：用加权的线性标量化（weighted linear scalarization）表示，即 \(A_{W_j, \mathbf{RR}}(\tau) = W_j \cdot (R_{v_1}(\tau), \ldots, R_{v_m}(\tau))^T\)，其中权重 \(W_j\) 位于单位单纯形内。
- **关键技术细节**：
    - 采用**Bradley‑Terry (BT) 模型**将偏好标签转化为可微分的概率估计：\(p(\tau \succ \tau' | R) = \sigma(R(\tau) - R(\tau'))\)，并利用交叉熵损失进行训练。
    - 引入**中心化机制**（centering mechanism）避免奖励尺度不一致。
    - 算法将问题形式化为一个**双层优化**：外层层优化价值系统权重，内层层优化价值基础，并优先保证基础学习的准确性。具体地，使用**拉格朗日乘子法**将约束（各价值基础的损失不超过目标）转化为目标函数，并采用**梯度下降‑上升（Gradient Descent‑Ascent, GDA）** 近似求解。
    - 动态更新每个价值的损失目标 \(L^*_{v_i}\)，采用**指数加权最小值**（exponentially weighted minimum）进行估计。
- **算法流程**（文字描述）：
    1. 随机初始化模型参数 \(\theta\)（奖励向量网络）、\(\omega\)（权重参数）和拉格朗日乘子 \(\bar{\lambda}\)。
    2. 对每个batch，计算价值系统损失和各价值基础损失。
    3. 计算归一化乘子，然后进行**梯度下降**更新 \(\theta\) 和 \(\omega\)（最小化增广拉格朗日函数）。
    4. 进行**梯度上升**更新乘子 \(\bar{\lambda}\)（最大化约束违反的惩罚）。
    5. 每隔 \(u\) 个batch，使用指数加权最小值更新各价值基础的损失目标 \(L^*_{v_i}\)。
    6. 重复步骤2‑5直至收敛。

### 3. 实验设计

- **数据集**：
    - **UltraFeedback**：包含383,796个反馈标注（对应64,000个prompt），每个prompt~4个回复，每个回复按4个目标（价值）标注（helpfulness, honesty, truthfulness, instruction following）。
    - **PKU-Align-Anything (text-to-text)**：包含31,430个标注的prompt-response对，每个对按5个价值标注（prompt following, objectivity, clarity, information richness, safety），并给出总体偏好（作为价值系统标签）。
- **Benchmark / 基线方法**：
    - **Armo-RM**：预训练的多目标奖励模型，使用Llama3-8B backbone和MLP输出权重，用MSE训练。
    - **BT-RM**：单目标奖励模型，仅优化价值系统损失（忽略价值基础损失），作为价值系统准确率的下界。
    - **SEQ-RM**：先单独训练价值基础（更新\(\theta\)），再冻结\(\theta\)优化价值系统权重（更新\(\omega\)），作为对比序列训练的基线。
    - 所有模型（除Armo‑RM外）使用相同的Llama3-8B-v0.1 backbone和线性head架构。
- **指标**：基础准确率（Grounding Accuracy）和价值系统准确率（Value System Accuracy），定义为1 - discordance（偏好预测与真实标签的不一致率）。

- VSL‑RM在价值系统准确率上接近单目标优化（BT‑RM），同时显著优于基线SEQ‑RM（统计显著，\(p<0.001\)），且基础准确率与SEQ‑RM持平。

- 算法动态优先基础学习，保证了价值系统建立在可靠的价值表示上，提高了可解释性。

### 7. 优点

- **方法创新**：首次将双层优化与拉格朗日乘子法应用于生成式AI的价值系统学习，同时学习价值基础和价值系统。
- **可解释性**：学到的价值系统以显式权重表示，可直接解释不同价值的相对重要性，优于隐式或黑盒方法。
- **优先机制**：通过约束优化确保基础学习优先于价值系统学习，避免陷入误导性的价值系统估计。
- **实验设计**：对比了多种基线（单目标、序列训练、预训练多目标模型），控制架构变量，统计检验充分。

### 8. 不足与局限

- **数据假设**：论文假设数据集中的价值偏好来自单一“社会基础”（social grounding）而非多个异质用户。当数据包含不同价值观的多个用户时，学习得到的价值系统只能代表多数意见，可能掩盖少数派偏好。
- **价值系统模型**：使用静态线性权重，可能无法捕捉真实价值偏好的上下文依赖性（例如用户对同一价值在不同prompt下的权重可能变化）。
- **实验覆盖**：
    - 仅在2个数据集上评估，且其中一个（UltraFeedback）是GPT-4生成的合成数据，人类标注数据仅有PKU。
    - 未在更大规模、更复杂的对话式数据集（如OpenAssistant）上验证。
    - 未进行RLHF微调后的最终生成质量评估，仅评估了奖励模型的对齐能力。
- **偏差风险**：数据集可能存在标注者偏见（如PKU中未区分个体标注者），聚合后可能放大主流观点。
- **效率**：算法引入了拉格朗日乘子的梯度上升更新和损失目标动态更新，增加了训练复杂度，但实际耗时并未显著高于基线（如文献所述）。
- **可扩展性**：算法中 \(u\)（更新目标周期）和 \(\lambda_0\)（乘子下限）等超参数需要手动调整。
